# 3. История браузера (Browser History)

## Описание задачи

Необходимо реализовать систему хранения истории браузера. Каждая запись содержит:

- URL  
- время посещения  
- флаг "закладка"  

## Обязательная часть

Реализовать:

- Навигацию «назад / вперед»  
- Очистку истории  
- Поиск по домену  

## Вариативная часть (выполнены задания 1 и 5)

Реализованы следующие дополнительные функции:

1. Сохранение истории в файл в формате Base64 (одна строка — одна запись)  
5. Топ-N переходов (наиболее частые переходы между доменами)


# Требования к выполнению

- Использовать линейные структуры данных (динамический массив или LinkedList)  
- Обосновать выбор структуры данных  
- Обработать пограничные случаи (пустые списки, выход за границы и т. д.)  
- Код должен быть читабельным и структурированным  
- Оформить репозиторий с кодом и выложить на github  

## Структура данных

В качестве основной структуры данных выбран динамический массив (список), потому что он даёт быстрый доступ по индексу (для навигации) и простое добавление в конец. Все граничные случаи обработаны: проверяется, пуста ли история, можно ли идти назад или вперёд, достаточно ли записей для топ‑N переходов

| Операция             | Сложность | Почему подходит                                             |
|----------------------|-----------|-------------------------------------------------------------|
| Доступ по индексу    | O(1)      | Навигация назад/вперёд требует мгновенного доступа          |
| Добавление в конец   | O(1)      | Новая страница всегда добавляется в конец                   |
| Удаление "будущего"  | O(n)      | Редкая операция, поэтому линейное время допустимо           |
| Поиск по домену      | O(n)      | История обычно небольшая, линейный поиск приемлем           |
